PROJECT TITLE:-
      Analysing Millet Seed Germination Prediction Using JEPA LLM Tuning Models And Crop Analysis
ABSTRACT:-
Millet is an important crop that is healthy, grows well in different climates, and supports sustainable farming. The ability of seeds to germinate properly is very important because it affects crop growth and final yield. Usually, checking seed germination is done manually, which takes time and may lead to mistakes. It is also difficult to check a large number of seeds quickly. To solve this problem, this project introduces a smart system to predict millet seed germination using JEPA, LLM models, and crop analysis.
In this system, JEPA is used to learn useful features from millet seed images without needing a large amount of labeled data. These features are then combined with crop and environmental details such as soil moisture, temperature, humidity, rainfall, soil pH, and seed type. A machine learning model uses this combined data to predict whether the seed will germinate or not. Along with this, a fine-tuned LLM explains the prediction in simple language and gives useful suggestions for better seed selection and crop management, making the system easy to understand and use.
The model performance is tested using measures like accuracy, precision, recall, F1-score, and confusion matrix. The system is developed as a web application where users can upload seed images, enter crop details, and get germination predictions along with helpful explanations. By combining image analysis, crop data, and AI explanations, this system provides a simple, fast, and cost-effective way to check seed quality. It can help farmers and researchers make better decisions, improve crop yield, and reduce seed wastage.
