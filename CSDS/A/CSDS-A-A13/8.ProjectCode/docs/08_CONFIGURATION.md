# Configuration

All settings live in **`.env`** in the product folder. `setup.bat` creates it from **`.env.example`** and generates a random `JWT_SECRET`. `.env` is private and never committed. Restart SeatWise (`stop.bat`, then `run.bat`) after changing it.

**SeatWise needs no external API keys or accounts** - it runs fully offline.

| Key | Default | What it does | How to set it |
|---|---|---|---|
| `APP_ENV` | `development` | `production` hides the demo password on the sign-in page. | Type the value. |
| `LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING` or `ERROR` for the API console and `logs/seatwise.log`. | Type the value. |
| `API_HOST` | `127.0.0.1` | Address the API listens on. Keep it local: other devices reach the API through the web server. | Leave as is. |
| `API_PORT` | `8113` | API port. Fixed so SeatWise can run next to other products. | Leave as is. |
| `WEB_PORT` | `5113` | Web app port (the address you open). Fixed; `vite.config.ts` refuses any other port. | Leave as is. |
| `JWT_SECRET` | random | Signs login tokens. Changing it signs everyone out. | Generated by `setup.bat`. To make your own: `python -c "import secrets; print(secrets.token_urlsafe(48))"` |
| `JWT_EXPIRE_MINUTES` | `720` | How long a sign-in lasts (12 hours). | A number of minutes. |
| `DATABASE_URL` | `sqlite:///data/app.db` | The SQLite file, relative to the product folder. Created on first start. | Leave as is, or point to another file. |
| `CORS_ORIGINS` | `http://localhost:5113,http://127.0.0.1:5113` | Browser origins allowed to call the API directly. | Comma-separated list. |
| `PUBLIC_BASE_URL` | `http://localhost:5113` | Address printed in the QR codes on seat slips. | For phones on the same Wi-Fi, use the PC's address, e.g. `http://192.168.1.20:5113` (find it with `ipconfig` -> IPv4 Address). |
| `SEED_DEMO_USERS` | `true` | Creates the demo accounts when the database has no users, and shows the demo buttons on the sign-in page. | `false` to turn off. |
| `DEMO_ADMIN_EMAIL` | `admin@seatwise.local` | Demo administrator email. | Any email-like text. |
| `DEMO_INVIGILATOR_EMAIL` | `invigilator@seatwise.local` | Demo invigilator email. | Any email-like text. |
| `DEMO_PASSWORD` | `SeatWise@2026` | Password of every demo account (applied when they are created). | Change it before sharing the machine. |
| `SOLVER_THREADS` | `0` | Halls solved in parallel; `0` = all CPU threads. | A number. |
| `SOLVER_HALL_BUDGET` | *(empty)* | Per-hall solver budget. Empty = the tuned value in `models/engine_profile.json` (0.15). | A decimal, e.g. `0.25` for more department-mix polish at the cost of time. |
| `SOLVER_MAX_RETRIES` | `5` | How often the engine may re-balance halls when one cannot be laid out. | A number. |
| `LOOKUP_RATE_LIMIT_PER_MINUTE` | `30` | Maximum public lookups per minute from one device. | A number. |

## Other settings

- **Default seating rules** (neighbours, roll-number gap, department mix, hall usage, accessible seats per hall) are workspace settings, changed in the product under **Settings** and stored in the database. See [07_USER_GUIDE.md](07_USER_GUIDE.md#settings-appsettings).
- **Engine profile**: `models/engine_profile.json` is written by `python -m ml.benchmark` and holds the tuned per-hall budget.
- **Ports in the frontend**: `frontend/vite.config.ts` reads `WEB_PORT` and `API_PORT` from the root `.env` with `strictPort: true`, so the web server never silently moves to another port.

## Checking the configuration

```bat
venv\Scripts\python scripts\check_env.py            :: local checks
venv\Scripts\python scripts\check_env.py --network  :: also checks the package registries
```
