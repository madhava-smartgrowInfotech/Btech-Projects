- Base paper facts: datasets: CK+, JAFFE and MUG (laboratory datasets; MUG peak frames, morphed to create two-emotion ground truth); method: cEmoGANs (encoder-decoder for identity-preserving latents + conditional GAN with a 6-d multi-hot label) generate complex expressions; a small CNN with sigmoid outputs is trained on the generated images; result: f-beta 0.99 / 0.99 / 0.80 and exact-match ratio 100 % / 99 % / 68.7 % on CK+ / JAFFE / MUG, measured on a 7:3 split of 15,000 images generated by the same cEmoGANs (EfficientNet-B0 baseline: f-beta 0.45 / 0.60 / 0.51); hardware: Intel i9-9900K, NVIDIA RTX A6000; identity: 98 % (CK+), 94 % (JAFFE), 99 % (MUG) of generated images with identity cosine similarity above 0.7

## 2. Architecture and code facts

- Backend `backend/app`: FastAPI 0.115 (requirements pin), SQLAlchemy/SQLite (`mosaic.db`), JWT (python-jose, HS256, 7-day expiry), bcrypt via passlib, PyTorch CPU, OpenCV Haar cascade `haarcascade_frontalface_default.xml`.
- Frontend `frontend/src`: Next.js 16.3.6, React 19.2.8, TypeScript, Tailwind 4, Framer Motion, GSAP, Lenis, Three.js (landing canvas), Recharts, zustand (persisted token), react-webcam.
- ML: `EmotionCNN` (4 conv blocks 32-64-128-128 with BatchNorm/ReLU/MaxPool, FC 2048-256, dropout 0.4, out_dim 7 or 18) - 770,130 parameters at 18 outputs; `ConditionalGenerator` (ConvTranspose 100+7 -> 256-128-64-32-1, Tanh, 64x64) 1,128,353 parameters; `ConditionalDiscriminator` (conv 32-64-128-256 + 16-d condition projection).
- Input: 64x64 grayscale scaled to [-1, 1]; labels: 7 basic + 11 compound (Du, Tao and Martinez pairs) = 18 sigmoid outputs; decision rule in `inference.py`: argmax over all 18 sigmoid outputs gives `dominant`; basic and compound lists are returned sorted.
- Training (`app/ml`): stage 1 softmax CNN, Adam lr 1e-3, batch 256, 5 epochs, class-weighted CE; cEmoGAN: Adam lr 2e-4 betas (0.5, 0.999), batch 64, 10 epochs on 400 images per class (2,800), label smoothing 0.9; final classifier: init from stage-1 `features.*`, BCE-with-logits, Adam lr 5e-4, batch 256, 5 epochs, real 28,709 + synthetic 2,200 (200 per compound class, condition 0.5/0.5 on the two components, multi-hot target = both basics + the compound).
- Endpoints: `POST /api/auth/register` (201/409/422), `POST /api/auth/login` (200/401), `GET /api/auth/me`, `POST /api/analyze` (multipart `image`; auth optional; 200 even when no face is found), `GET /api/history?limit&offset`, `GET /api/history/{id}`, `DELETE /api/history/{id}` (204), `GET /api/health`, static `/api/media/thumbs/{id}.jpg`.
- Database tables: `users(id, name, email unique, password_hash, created_at)`, `analyses(id, user_id FK, created_at, face_detected, basic_emotions JSON, compound_emotions JSON, dominant JSON, thumbnail_path)`.
- Ports: code defaults 8000 (API) and 3000 (UI); during this run port 8000 was occupied by another product, so the API ran on 8116 and the UI was a production build (`next build` + `next start -p 3000`) with `NEXT_PUBLIC_API_URL=http://localhost:8116/api`.

## 11. Known product defects found while measuring (all left unchanged)

1. Compound outputs are inert on real faces and cannot rank synthetic compound classes (see section 6); `dominant` is therefore never a compound label.
2. The cEmoGAN does not obey its condition (section 7).
3. `ResultsView` uses `result.thumbnail_url` directly, a relative path that resolves against the UI origin, so the thumbnail shows a broken image; `thumbnailUrl()` in `lib/api.ts` is never applied there.
4. `/app/history/[id]` exists but nothing in the UI links to it.
5. A hard reload of a protected route (`/app`) lands on `/login` even with a stored token (the guard runs before the persisted store is read).
6. `POST /api/analyze` answers 200 with `face_detected: false` where `API_CONTRACT.md` says 422; undecodable files cause HTTP 500.
7. Training/serving mismatch: training faces are 48x48 aligned FER crops, serving uses a Haar crop of the photo.
8. `requirements.txt` pins `bcrypt==4.0.1` for a reason: bcrypt 5 breaks passlib hashing (seen in the first test run).
9. No `run.bat`/`setup.bat`/`.env.example` exist in the code folder; ports are 8000/3000 not the batch prompt's 8116/5116.
