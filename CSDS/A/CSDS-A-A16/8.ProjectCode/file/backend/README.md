# Mosaic — backend

FastAPI service that detects faces in an image and estimates both basic and
compound (mixed) emotions using a CNN multi-label classifier trained with
GAN-based data augmentation for the compound classes.

## Setup

```bash
python -m venv .venv
./.venv/Scripts/activate      # Windows
pip install -r requirements.txt
```

## Train the models (one-time, ~30-60 min on CPU)

Downloads FER2013 (public, no auth) automatically on first dataset load.

```bash
python -m app.ml.run_pipeline
```

This runs three stages, in order, and writes real metrics to
`checkpoints/training_log.txt`:

1. **Basic backbone** — a CNN trained on real FER2013 images to classify the 7
   basic emotions (angry, disgust, fear, happy, sad, surprise, neutral).
2. **cEmoGAN** — a conditional GAN trained on the same real images, learning to
   generate a face conditioned on an emotion vector.
3. **Final classifier** — an 18-label (7 basic + 11 compound) multi-label CNN,
   initialized from the stage-1 backbone and fine-tuned on real basic-labeled
   images *plus* synthetic compound-labeled images generated by the cEmoGAN
   (e.g. blending "happy" + "surprise" conditions to synthesize a "happily
   surprised" face). This is what the API actually serves predictions from.

The compound taxonomy (11 classes) follows the Du, Tao & Martinez compound
facial-expression categories.

## Run the API

```bash
uvicorn app.main:app --reload --port 8000
```

Docs at `http://localhost:8000/docs`. See `../API_CONTRACT.md` for the full
endpoint reference.
