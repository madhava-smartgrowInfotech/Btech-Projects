# PLAN - ClauseGuard

**Architecture:** React+Vite (JS, port 5106) -> FastAPI backend (port 8106, SQLite) -> Gemini API
(classification, explanations, summaries, embeddings). Local vector search over embeddings via
NumPy (no pgvector). NetworkX in-memory graph per contract for risky-combination detection
(no Neo4j). PyMuPDF/python-docx for parsing.

**Backend endpoints (all under /api):**
- POST /auth/register, POST /auth/login -> JWT
- POST /contracts/upload (multipart PDF/DOCX) -> parses, splits clauses, classifies, scores,
  detects predatory clauses + risky combos, stores, returns contract_id
- GET /contracts -> list user's contracts
- GET /contracts/{id} -> full report (grade, summary, clauses, flags)
- GET /contracts/{id}/clauses/{clause_id} -> clause detail (type, explanation, rule, safer wording)
- GET /contracts/{id}/graph -> nodes/edges for clause graph + risky combos
- GET /eval/metrics -> CUAD classification + predatory-detection scores (from experiments/eval/metrics.json)
- POST /eval/run (optional trigger, else pre-baked at build time)

**DB tables (SQLAlchemy/SQLite):** users, contracts, clauses (text, page, type, embedding blob,
complexity fields), flags (clause_id, rule_id, severity, reason, safer_wording), combo_flags
(contract_id, clause_ids json, reason).

**Screens:** Landing, Login/Register, Upload, Contract report, Clause detail, Clause graph, Evaluation.

**Data:** CUAD (Atticus) sample committed under data/sample/cuad_sample.json (subset of QA pairs
across categories, generated by scripts/download_data.py from Hugging Face
theatticusproject/cuad-qa, seeded/deterministic subset since full corpus is large); Indian
predatory-clause rule set authored in backend/app/services/rules.py (7 rule types from spec);
curated labelled test contracts in data/sample/predatory_test_set.json for F7 eval.

**Predatory rules (F3):** restraint of trade, penalty vs liquidated damages, unilateral
termination, unlimited liability, one-sided arbitration, auto-renewal, IP overreach.

**Risky combos (F4, NetworkX):** unilateral termination + no-refund + penalty; restraint of
trade + unlimited liability; auto-renewal + unilateral termination.

**Complexity score (F5):** Flesch reading ease, legalese-term density, cross-reference count,
avg sentence/clause length -> weighted grade A-F.
