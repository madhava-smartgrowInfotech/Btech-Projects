## 2. What the product actually is (read from the code)

- Python **standard library only** backend (`http.server`), 5 simulated clients x 5 sentences each (25 records), a **character-bigram language model** (33-symbol alphabet, 33x33 = 1,089 parameters) standing in for an LLM adapter update. No PyTorch / Flower / Hugging Face model is used; it is a demonstrator.
- Training: each client's bigram-count vector is L2-clipped (C = 25), summed, Gaussian noise N(0, (sigma*C)^2) is added per coordinate (sigma = 3), and the result is divided by the client count. All 5 raw update norms (25.22-28.23) exceed C, so all 5 are clipped (scale 0.886-0.991).
- Unlearning: the stored clipped update of the chosen client is subtracted from the noisy aggregate and the sum is divided by (n-1). The same stored noise vector is kept.
- Certification: re-computes the retained-only aggregate from the stored updates **and the same noise** and takes the L2 distance; status CERTIFIED if distance <= 1e-10 and utility retention >= 70 %. Because both sides use identical stored values, the check is exact by construction (algebraic identity), not an independent retrain.
- Epsilon: epsilon = sqrt(2 ln(1.25/delta)) / sigma, delta = 1e-5 -> **epsilon = 1.6149**. This is the classical one-shot Gaussian-mechanism bound, which is only valid for epsilon < 1 (needs sigma > 4.845); the default sigma = 3 is outside that range.
- Membership inference: loss-based attack AUC of the client's 5 records vs 5 fixed non-member sentences (AUC resolution 0.04).
- Audit: append-only JSONL, each record SHA-256 over previous hash + canonical JSON; `verify()` re-walks the chain.
- Utility score = 0.65 * next-char accuracy + 0.35 / (1 + ln(1 + perplexity)); retention = after/before x 100 (capped at 100).

### 5.11 Differential-privacy facts

- delta 1e-5; epsilon = 4.8448/sigma. sigma=3 -> 1.6149; epsilon < 1 needs sigma > 4.845.
- Noise std per coordinate at default = 75; expected noise L2 = 2475 versus clipped client update norm 25 -> signal per client is ~1 % of the noise norm.
- The noise vector is drawn once at training and **reused** after unlearning; the epsilon on the certificate is the training-time epsilon, unchanged, and no privacy accountant exists.

### 5.12 Two further findings computed while writing the report

- Exact analytic Gaussian mechanism (Balle and Wang, ref [19]), delta = 1e-5: sigma = 3 -> epsilon 1.271 (reported 1.615, conservative there); sigma = 0.5 -> 9.997 (reported 9.690: the classical formula UNDERSTATES epsilon where the model is useful); sigma = 4.85 -> 0.750.
- Because the noise vector is reused, n*theta_before - (n-1)*theta_after equals the removed client's clipped update (rounding error ~1e-13): anyone holding both released models can recover the update. The API never returns parameter vectors, so this is not reachable through the application.
