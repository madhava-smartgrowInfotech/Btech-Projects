# TalentTrack - build plan

**Architecture:** React + Vite (5209, proxies `/api`) -> FastAPI (8209) -> SQLite (`data/app.db`) + local code judge (subprocess per test) + scikit-learn resume classifier (`models/`) + Gemini API.

**Endpoints (all under `/api`):**
- `auth/register`, `auth/login`, `me`, `me/dashboard` (level ladder, readiness, notifications)
- `practice/topics`, `practice/start`, `practice/{id}/submit`, `practice/explain/{qid}` (F1 aptitude, F3 technical)
- `problems`, `problems/{slug}`, `problems/{slug}/run`, `problems/{slug}/submit`, `submissions` (F2 judge)
- `contests`, `contests/{id}`, `contests/{id}/leaderboard`, `leaderboard` (F4)
- `interviews/start`, `interviews/{id}/submit`, `interviews/{id}`, `interviews/expert/*` (F5, F6)
- `resume/analyze`, `resume/roles`, `resume/latest` (F7)
- `drives`, `drives/{id}/shortlist`, `drives/{id}/status`, `drives/{id}/invite` (F8)
- `analytics/readiness` (F9)

**Tables:** users, questions, test_attempts, answer_logs, submissions, contests, interviews, resumes, drives, applications, notifications. Coding problems live in `data/problems.json` (generated by a seeded script).

**Levels:** L1 Foundation -> L2 Aptitude (best aptitude >= 60%) -> L3 Coder (3 accepted problems + technical >= 60%) -> L4 Interview-ready (AI interview >= 6/10 + resume ATS >= 55) -> L5 Job-ready (expert interview passed, badge).

**Readiness score (0-100):** 25% aptitude + 20% technical + 25% coding + 15% interview + 15% ATS.

**Screens:** Landing, Login, Candidate dashboard, Aptitude/technical tests, Coding + Monaco editor, Contests + leaderboard, Mock interview + report (and expert queue), Resume analyser, Recruiter drives + shortlist, Readiness analytics.

**Data:** Kaggle Engineering Aptitude Test Questions (MIT, committed, 560 MCQs), Kaggle Resume Dataset (CC0, `Resume.csv` committed + 24 sample PDFs), 30 original coding problems with seeded hidden tests, original technical MCQs for DBMS / OS / networks / programming.

**Model:** TF-IDF + Logistic Regression role classifier (24 categories), trained on CPU in seconds; metrics in `experiments/`.
