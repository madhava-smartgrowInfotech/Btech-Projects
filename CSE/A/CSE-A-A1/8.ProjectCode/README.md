# Adaptive Learning Intelligence Platform

A B.Tech final-year project: an adaptive learning platform that lets students
upload academic material (syllabi, notes, timetables, question banks),
automatically extracts subjects/topics, answers questions using a
Retrieval-Augmented Generation (RAG) pipeline over the uploaded content, and
builds a personalized, priority-ranked study roadmap from quiz performance.

## Features

- **Auth** — simple username/password registration & login (hashed passwords).
- **Document upload & analysis** — PDF / DOCX / TXT support. Text is extracted,
  chunked, and scanned for subject/unit/chapter hints and TF-IDF keywords to
  build a structured "knowledge repository".
- **RAG-based Q&A** — ask natural-language questions; the app retrieves the
  most relevant chunks from *your* uploaded documents (TF-IDF + cosine
  similarity) and answers from them. If an `ANTHROPIC_API_KEY` environment
  variable is set, answers are generated by Claude using the retrieved
  content as context; otherwise the app falls back to a built-in extractive
  answering method so it works fully offline with zero API cost.
- **Auto-generated quizzes** — multiple-choice quizzes are generated
  automatically from each document's key terms.
- **Adaptive roadmap** — quiz results are tracked per topic; a
  priority-ranked roadmap (High / Medium / Low) highlights the topics you're
  weakest on.
- **Dashboard** — upload count, questions asked, quiz attempts, and a
  subject-wise performance chart (Chart.js).

## Tech Stack

- Backend: Python, Flask
- Database: SQLite (zero setup)
- Retrieval: scikit-learn (TF-IDF + cosine similarity)
- Document parsing: pypdf, python-docx
- Frontend: Bootstrap 5, Chart.js (via CDN)
- Optional generation: Anthropic API (Claude)

## Setup

1. **Create a virtual environment (recommended)**

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **(Optional) Enable real generative answers**

   The app works fully out of the box without this step. To get natural
   -language generated answers instead of the extractive fallback, set:

   ```bash
   export ANTHROPIC_API_KEY=your_key_here     # Windows: set ANTHROPIC_API_KEY=your_key_here
   pip install anthropic
   ```

4. **Run the app**

   ```bash
   python app.py
   ```

   The app starts at `http://127.0.0.1:5000`. The SQLite database
   (`instance/app.db`) is created automatically on first run.

5. **Try it out**

   - Register an account.
   - Go to **Upload**, and upload `sample_data/sample_notes_data_structures.txt`
     (included) as a quick demo, or upload your own notes.
   - Go to **Ask AI** and ask a question about the uploaded content, e.g.
     *"What is the LIFO principle?"*
   - Go to **Documents → Generate Quiz** to take an auto-generated quiz.
   - Check **Roadmap** to see your weak topics ranked by priority.

## Notes for Viva / Demo

- The retrieval component implements the core RAG idea described in the
  project abstract: chunking documents, indexing them, retrieving the
  most relevant chunks for a query, and generating a context-grounded
  answer — without requiring any paid API or GPU, so it is easy to run on
  any laptop for a demo.
- The adaptive roadmap logic classifies each topic's priority using the
  quiz accuracy for that topic: **<50% → High priority**,
  **50–80% → Medium**, **>80% → Low**.
- Everything is intentionally kept dependency-light (Flask + scikit-learn +
  SQLite) so the whole project can be demonstrated without any external
  services, while still supporting an optional real LLM (Anthropic Claude)
  plug-in for a stronger live demo if you have an API key.
