## 4. Architecture summary

- Flask app (`app.py`, port 5000, untouched) + FastAPI layer (`backend/main.py`, port 8312) + React 19/Vite 8 front end (`frontend/`, port 5312, kit V2 Neo Brutal Grid). SQLite `pneumonia_app.db` (table `predictions`, 10 columns); images in `static/uploads` and `static/heatmaps`; weights in `saved_models/`.
- Pipeline: decode grayscale -> resize 224x224 -> CLAHE (clip 2.5, 8x8) -> Gaussian 3x3 -> RGB, /255 -> CNN (4 conv blocks 32/64/128/256 + BN + MaxPool, GAP, Dense 512 + BN + Dropout .35, Dense 128 + Dropout .25, softmax 3) -> Grad-CAM on `last_conv`, overlay alpha 0.4.
- Model: 590,019 parameters (588,035 trainable, 1,984 non-trainable), 2.36 MB float32.
- Not implemented: U-Net lung segmentation (objective 2), Monte Carlo Dropout, semi-supervised learning.
- Shipped Grad-CAM cannot reach a nested transfer-learning backbone (verified with MobileNetV3Small): `Output with path 0 is not connected to inputs`.
- `model/train.py` (original) trains with rescale only (no CLAHE) while inference applies CLAHE; `scripts/train_experiment.py` uses the inference preprocessing.
