About This Project

Project Title

Pneumonia Detection Using Deep Learning

Abstract

Pneumonia remains one of the leading causes of illness and death worldwide, especially among children and elderly patients. Manual diagnosis from chest X-ray images depends on radiologist availability and can be time-consuming. This system applies image preprocessing, CNN-based deep learning, and classification techniques to classify chest X-ray images into Normal, Bacterial Pneumonia, or Viral Pneumonia categories, and generates heatmap-based visual explanations to highlight affected lung regions for clinical decision support.

Proposed System Pipeline
  1. Image upload via web interface
  2. Preprocessing: resize (224×224), CLAHE contrast enhancement, normalization
  3. Data augmentation during training (rotation, zoom, shift, flip)
  4. CNN-based feature extraction and 3-class classification
  5. Grad-CAM heatmap generation for explainability
  6. Result storage and history tracking (SQLite)
