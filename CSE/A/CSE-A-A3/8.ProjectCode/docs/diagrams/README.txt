Design diagrams for Multi-Disease Prediction Using Machine Learning (generated by scripts/make_diagrams.py, matplotlib, 150 dpi).
Each mirrors the code: generate_data.py -> train_models.py -> app.py -> backend/main.py (FastAPI, 7 routes) -> React frontend.
There is no database, no authentication and no stored patient data; the ER diagram is the logical data model.
