## 1. Project

- Title: Credit Card Fraud Detection Using Machine Learning; product name **SecurePay AI** (React UI on 5304, Flask API on 8304).
- Base paper: Neto, Amaral, Temporao, 'Fraud Detection in Credit Card Transactions Using Quantum-Assisted Restricted Boltzmann Machines', IEEE Access vol. 14, 2026, doi 10.1109/ACCESS.2026.3683308. Its Table 1 (read from the PDF): PCD 84/86/81/83 (acc/prec/rec/F1 %, 2 min), SAS 85/94/82/88 (4 h), QS 85/91/79/84 (1.8 h); real Stone data, 145 M transactions, ~19 thousand fraud, balanced to 39 thousand 50/50, 80/20 split, 50 epochs.
- Implementation: Gaussian-Bernoulli RBM classifier (GRBMC) in numpy with three trainers: classical PCD, simulated-annealing sampling (SAS), quantum-inspired sampling (QS, classical simulation, no quantum hardware). Ensemble = mean of the three probabilities, threshold 0.5, risk bands 0.4/0.7.

## 2. Dataset and split

- `data/creditcard_synthetic.csv`: 39,000 rows x 29 columns, fraud 19,500, legitimate 19,500 (50/50). **Synthetic**: generated by `backend/synthetic_data.py` (numpy seed 42); it imitates the base paper's balanced 39 k set but is not Stone data and has no licence constraints. Mean amount: fraud 368.20, legitimate 85.21.
- The backend builds its pipeline from an 8,000-row random sample (random_state 42): one-hot, z-score on 24 numeric columns, correlation filter 0.95 (dropped: none), random-forest importance top-18, 80/20 stratified split -> train [6400, 18], test [1600, 18] (805 fraud in test).
- Features kept: Amount, V3, Card_Present, V17, V7, Country_Match, V10, Transaction_Type_Online, V14, Transaction_Type_Chip, Merchant_Category_Grocery, V1, V6, V16, V2, V11, V4, V19.

## 4. Batch route (defect found)

`predict_batch` (the Bulk page) drops to the 18 selected columns and then calls `scaler.transform` on only the selected numeric columns (13 of the 24 the scaler was fitted on); scikit-learn raises, a bare `except: pass` swallows it, and the models receive UNSCALED values. `predict_single` (the Verify page) scales BEFORE selecting columns and is correct: its live probabilities equal the offline scaled ones (see experiments/sample_io.json).
- Fresh 2,000-row balanced batch, ensemble, as_served_no_scaling: accuracy 50.2%, precision 50.1%, recall 100.0%, F1 66.8%, ROC-AUC 0.893, FP 995, FN 0.
