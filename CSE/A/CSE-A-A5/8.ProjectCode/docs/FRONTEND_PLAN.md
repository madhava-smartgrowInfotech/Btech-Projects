# Frontend Plan - CipherGuard Shield (CSE-A-A5)

Design kit: **V5 - Kinetic Mono** (JavaScript `.jsx`) · Ports: backend **8305**, frontend **5305**

The existing UI is a plain HTML/JS page in `web/` served by FastAPI. It stays untouched and working.
The new React app lives in `frontend/` and talks to the same FastAPI backend (`cipherguard/api/main.py`).
CORS is already `allow_origins=["*"]`, so no backend change is needed.

---

## 1. Backend endpoint inventory

Source: `cipherguard/api/main.py` (FastAPI 0.110, in-memory alert log, no auth, no database).

| # | Method | Path | Request | Response | Errors |
|---|--------|------|---------|----------|--------|
| 1 | GET | `/api/health` | - | `{status, product, version, engine_loaded}` | - |
| 2 | GET | `/api/metrics` | - | contents of `reports/metrics.json`: `data_mode, dataset_rows, splits{train,val,test}, accuracy, precision, recall, f1, roc_auc, confusion_matrix[[TN,FP],[FN,TP]], confusion_labels, xgb_accuracy, cnn_accuracy, meta_coef, meta_intercept, class_balance{neg,pos}, input_dim, cnn_backend, technology{model_a,model_b,fusion,dataset,crypto}` | 404 / 503 / 500 |
| 3 | POST | `/api/ids/score` | JSON flow record, any subset of the 42 UNSW-NB15 features (missing ones get defaults) | `{label: "attack"\|"normal", confidence, severity: low\|medium\|high\|critical, xgb_score, cnn_score, alert?}` (`alert` only when attack) | 400 invalid, 503 / 500 engine |
| 4 | POST | `/api/ids/score-batch` | multipart `file` = CSV (<=10 MB, <=10 000 rows) | `{total, attack_count, normal_count, results[{row,label,confidence,xgb_score,cnn_score}]}` (results capped at 1000) | 400 / 500 / 503 |
| 5 | GET | `/api/alerts?limit=` | limit 1-500, default 100 | `{alerts[{timestamp,severity,confidence,label,features,scores{xgb,cnn}}], total}` | - |
| 6 | DELETE | `/api/alerts` | - | `{cleared: true}` | - |
| 7 | POST | `/api/crypto/encrypt` | `{plaintext}` (<=1 MB) | `{ciphertext, nonce, tag, ephemeral_public, algorithm, key_exchange, note}` | 400 |
| 8 | POST | `/api/crypto/decrypt` | `{ciphertext, nonce, tag, ephemeral_public}` | `{plaintext, verified}` | 400 bad base64 / tag mismatch |
| 9 | POST | `/api/crypto/encrypt-file` | multipart `file` (<=5 MB) | `{filename, ciphertext, nonce, tag, ephemeral_public, original_size, encrypted_size}` | 400 |
| 10 | GET | `/docs`, `/openapi.json` | - | Swagger UI | - |
| 11 | GET | `/`, `/static/*`, `/{path}` | - | legacy `web/index.html` (kept as is) | - |

The 42 scoring features (`cipherguard/ids/features.py`): categorical `proto` (tcp, udp, icmp, arp, ospf, igmp),
`service` (-, http, ftp, smtp, ssh, dns, ftp-data, pop3, dhcp, ssl, snmp, radius, irc), `state` (FIN, INT, CON, REQ,
RST, ECO, ACC, CLO, PAR, URN, no, -); the rest numeric (dur, spkts, dpkts, sbytes, dbytes, rate, sttl, dttl, sload,
dload, sloss, dloss, sinpkt, dinpkt, sjit, djit, swin, stcpb, dtcpb, dwin, tcprtt, synack, ackdat, smean, dmean,
trans_depth, response_body_len, ct_*, is_ftp_login, is_sm_ips_ports).

**No additive endpoint is required.** Everything the new screens need is returned by the endpoints above.
Sample CSV for the batch screen: `data/raw/synthetic_demo.csv` (generated by the training pipeline).

## 4. Setup notes and open items

- **Ports**: there was no `.env`. Added `.env` / `.env.example` (ports only, no secrets) with `BACKEND_PORT=8305`, `FRONTEND_PORT=5305`; Vite
  serves on 5305 and proxies `/api` to 8305. The legacy `web/` UI keeps working at `http://localhost:8305`.
- **Kit layout**: the kit ships `src/index.css` (tokens + Tailwind) rather than `styles/tokens.css`; the entry file imports `./index.css`.
  The kit has no top-level config files, so Tailwind comes from `@tailwindcss/vite`.
- **Backend blocker found and fixed**: the shipped `models/*.joblib` were pickled with scikit-learn 1.5.0, but `requirements.txt` pinned
  1.4.1.post1, so the engine failed to load (`Can't get attribute '_RemainderColsList'`) and `/api/ids/score` returned 500. The pin is now
  `scikit-learn==1.5.0` (matches the artifacts - no retraining, `metrics.json` unchanged). No Python logic changed.
- **Launchers**: `run.bat` now reads `.env`, starts the API (own window, 8305) and the Vite console (5305) and opens the browser; `app.py` reads
  `BACKEND_PORT` from `.env`. `Dockerfile` / `docker-compose.yml` still serve the legacy dashboard on 8000, untouched.
- **Kit adaptations** (in the copies under `frontend/src`, never the kit): `AppShell`, `CommandPalette`, `ActivityLog`, `Logo` and `display.jsx` were product-coupled
  (auth, taxpayers, pipeline) and were rewired to this product; `Stepper` got a flexible column count; added `lib/reduced.js`, `lib/activity.js`, `api.js`, `format.js`
  and `components/three/Backdrop.jsx` (lazy-loaded three.js wire grid) which the kit components import.
