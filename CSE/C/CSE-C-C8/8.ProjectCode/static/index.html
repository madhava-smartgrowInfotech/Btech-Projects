About PeerScope

What PeerScope does

PeerScope is an AI-assisted research-paper evaluation and reviewer-recommendation tool. Upload a PDF and receive a preliminary assessment (historical decision signal, structural checks, local AI critique, related-literature context) plus ranked reviewer recommendations with a transparent audit trail.

Pipeline

PDF text extraction → normalization & section detection → feature extraction → trained decision model + structural signals + local language-model review + literature grounding → review synthesis → expertise matching → auditable ranking → dashboard & export.

Reviewer matching (auditable)

final = 0.55·expertise_similarity + 0.20·keyword_overlap + 0.15·method_overlap + 0.10·availability − conflict_penalty, normalized to 0–100. Weights are configurable in app/config.py.

Responsible Use

  • AI output can contain errors; scientific validity requires human expertise.
  • Reviewer recommendations are decision-support suggestions, not assignments.
  • Retrieved literature is supporting context, not proof of novelty.
  • Verify important claims and conflicts of interest independently.
  • Do not use PeerScope as the sole basis for publication decisions.

Privacy

PDFs are processed locally. Only title/topic keywords are sent to the public OpenAlex API for literature context (no document upload, no paid APIs, no credentials). Analyses store metadata, not private document copies.
